# v74 experiment and verification evidence

This directory contains only experiment and verification materials associated
with the v74 work. Manuscript source files, the compiled paper, and the ZIP
package that contained them are intentionally excluded from this repository.

Retained materials include the reviewer-gate and parameter-sweep scripts and
results, ReceiptBridge verification inputs, the operator receipt-bridge
experiment, and the RSP validation record. The `.gitattributes` file keeps
these evidence files byte-stable across Git checkouts.
